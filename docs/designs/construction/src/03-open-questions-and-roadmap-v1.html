1. How to use this document

Documents 1 and 2 are specifications. This one is the work queue. Every item is a thing the design assumes or does not know, together with the cheapest check that settles it. A revision of the set is cut when a batch of these is answered. Priority reflects how much of the design falls over if the answer is the unwelcome one.

PriorityMeaning
P1The architecture changes if the answer is bad. Settle first.
P2A feature changes shape or is cut. Settle before that phase starts.
P3Detail or polish. Settle during implementation.
