1. How to use this document

Documents 1 and 2 are specifications. This one is the work queue: everything the design assumes or does not know, with the cheapest check that settles it. A revision of the set is cut when a batch is answered. Priority reflects how much of the design falls over if the answer is unwelcome: P1 changes the architecture, P2 changes or cuts a feature, P3 is detail.
